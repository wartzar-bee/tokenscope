Make your own card

One command. Reads your Claude Code logs locally and shows where your spend actually went — usually mostly re-sent context.

npx @wartzar-bee/tokenscope --share

Privacy by construction. tokenscope is read-only and local: it never sends your logs anywhere. A share link carries only aggregate numbers (totals + percentages) in the part of the URL after #, which browsers never transmit to a server — so even this page renders it entirely in your browser. No file paths, no prompts, no responses, no tool names. Source on GitHub.
